# NFC Portfolio

这是一个可以直接部署到 GitHub Pages 的静态作品展示页。

## 你只需要改 4 件事

1. 修改 `index.html` 里的作品名称、年份、作者、说明。
2. 把主图放进 `assets/cover.jpg`。
3. 把其他图片放进 `assets/01.jpg`、`assets/02.jpg`。
4. 按 `index.html` 里的注释，把 placeholder 删除并启用 `<img>` 标签。

## GitHub Pages

上传所有文件到一个公开 GitHub 仓库后：

Settings → Pages → Build and deployment → Deploy from a branch  
Branch: `main`  
Folder: `/(root)`

发布后网址通常是：

`https://你的用户名.github.io/仓库名/`

把这个 HTTPS 地址写入 NFC Tools 的 “URL / URI” 记录即可。
